サインと採点について
チャートの L／S はエントリーサイン、E は決済サインです（もちぽよアラートと同じ条件で表示。判定条件の詳細は非公開です）。E が出るまで次のサインは出ません。E の横の数字はサインの足の終値からの値幅です。
A/B/C採点：エントリー時の確定足で、判定パネルの3項目（EMAパーフェクトオーダー・RCI・MACD）がそろっているかを採点します。3/3＝A、2/3＝B、1以下＝C。ダイバージェンス（通常＝反転の兆し／ヒドゥン＝トレンド継続の兆し。ヒドゥンは点線で表示）・上位足PO・RCI(14)(18)は参考表示です。
ポイント：合計pips × 武器の倍率（負けた分はマイナス）＋完走10P＋A判定・勝率などのボーナス。所持ポイントは0未満になりません。武器は12段階（1,000通貨〜300万通貨）。
値動きは、実際のGBP/JPY 5分足の統計的な性質を参考に乱数で生成した架空のものです。相場セット（第1期〜第12期）はそれぞれ別の3年分で、合計36年分の場面から練習できます。指標やイベントも架空のカレンダーです。実在の相場や特定の期間を再現したものではなく、将来の値動きや成績を示すものでもありません。

このゲームの値動きは、実際の為替相場（GBP/JPY）の統計的な性質を参考に乱数で作った架空のものです。実在の相場や特定の期間を再現したものではありません。表示される経済指標やイベントも架空のカレンダーです。

トレード手法の練習・学習を目的としたゲームであり、投資助言や特定の取引の推奨ではありません。ゲーム内の成績やポイントは、実際の取引の成果を保証するものではありません。ポイントは負けた分だけ減ります（0未満にはなりません）。実際の取引はご自身の判断と責任で行ってください。

あそびかた

1. 開始する … ボタンを押すとチャートが動きます。1ゲームは5分足150本（約12時間分）。右上の「速度」で早送りできます。

2. 買／売ボタンでエントリー、決済ボタンで手じまい … ポジションは1つずつ。損切り・利確は設定で選べます（自動で決済）。ポジション保有中はチャート上の損切り・利確のラインを上下にドラッグして動かせます（「なし」のときはラインが出ないので、設定で選んでから動かしてください）。

3. 採点 … エントリーした瞬間に、判定パネルの3項目（EMAパーフェクトオーダー・RCI・MACD）がそろっているかをチェック。3つそろえばA、2つでB、1つ以下はC。判定パネルの「今ロングなら／今ショートなら」で、いま入った場合の判定が分かります。

サインと決済サイン … チャートの L／S はエントリーサイン、E は決済サイン（もちぽよアラートと同じ条件）。E の横にサインからの値幅が出ます。設定の「決済目安サイン」で、E の条件をMACDクロスやEMA20抜けに変えて試すこともできます。ポジション保有中に条件を満たすと判定パネルに「今が決済サイン！」と出ます（練習モードのみ）。

ダイバージェンス … 価格とMACDの食い違いを自動で検出して表示します（参考）。通常のダイバージェンス（反転の兆し）は破線、トレンド中のヒドゥンダイバージェンス（継続の兆し）は点線で、判定パネルにも「強気／弱気」「ヒドゥン」の別が出ます。

4. 練習モードと実戦モード … 練習は条件とサインを表示。実戦は隠して自分で判断し、決済後に答え合わせ。

5. クエスト … 場面と条件が決まった修行を順番にクリア。報酬ポイントと仲間の解放があります。

6. ポイントと武器 … 勝つと増え、負けると減ります。武器庫で武器を買うと取引数量の上限と倍率が上がります。

7. 引き継ぎコード … 記録はこのブラウザに保存されます。結果画面やプレイヤー情報からコードを控えておくと、別の端末や消えたときに復元できます。
